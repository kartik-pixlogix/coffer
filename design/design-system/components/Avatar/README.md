# Avatar

Use an avatar with initials for every person, company and vault provider; a person's small coloured dot shows which partner they are or bill to.

- Classes: `cf-avatar` (36), `--sm` (28), `--lg` (48), `--xl` (64); `--graphite` for companies; `--tile` (rounded square) for vault providers. Dot: `<span class="cf-avatar-dot" style="background:var(--partner-n)">`.
- The dot never carries meaning alone: the person's name or the partner name is always nearby, or in `aria-label`.
