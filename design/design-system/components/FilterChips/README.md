# Filter chips

Use filter chips for one-tap filters above a table (All / Pending / Approved / Rejected) with live counts, and as removable tokens for filters already applied.

- Toggle chips: `<button class="cf-chip" aria-pressed>` with a `t-money-sm` count; the pressed chip is lime. A chip with no results can be disabled.
- Applied filters: `cf-chip` with a `cf-chip-x` remove button labelled "Remove … filter", plus a Clear all link.
