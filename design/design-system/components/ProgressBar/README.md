# Progress bar

Use a progress bar for a known part of a whole (loan repaid, equity share, plan usage), always with the numbers written beside it.

- Markup: `<div class="cf-progress" role="progressbar" aria-valuenow aria-valuemin aria-valuemax aria-label>` › `<span style="width:N%">`. Variants: default `chart-ink`, `--lime` (equity), `--warn` (80% or more of a limit), `--neg` (over), `--thin` (4 px in lists).
