# Empty state

Use an empty state when a module has nothing in it yet: a lime icon disc, what's missing ("No income yet"), one sentence on what adding it does, and the action that fills it; for a filter with no results use the smaller row in Data table.

- Markup: `cf-empty` › `cf-empty-ic` (or `--muted`) › heading › `<p>` › actions. Never show an empty chart or a table of zeros in its place.
