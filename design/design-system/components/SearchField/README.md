# Search field

Use the 54 px top-bar search with the ⌘K hint to jump anywhere in Coffer (it opens the command palette), and the 40 px pill search to filter the list on the current page.

- Top bar: `<label class="cf-search">` › search icon + `<input type="search">` + `<span class="cf-kbd">⌘K</span>` (show Ctrl K on Windows). In-page: `cf-inwrap cf-inwrap--sm` with a full radius.
- Show a clear button once there's a query. Placeholders name what is searched ("Search expenses").
