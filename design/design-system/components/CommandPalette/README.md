# Command palette

Use the command palette (⌘K or Ctrl K, or a click on the top-bar search) to jump to any page, record or action by typing; results are grouped as Pages, Actions, People and Vault, and the first result is active.

- Markup: a centred `cf-pop cf-cmdk` dialog › `cf-cmdk-input` (combobox) › `cf-menu` listbox of `cf-menu-item` options with `cf-menu-label` group titles › `cf-cmdk-foot` key hints.
- Vault results show names only, never secrets, and respect the person's access.
