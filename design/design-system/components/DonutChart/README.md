# Donut chart

Use a donut for shares of one total with at most six slices, with the total in Bricolage Grotesque in the hole and a legend that repeats every name and percentage.

- Markup: `<div class="cf-donut" role="img" aria-label="…every slice…" style="background:conic-gradient(…)">` › `cf-donut-hole`. Leave a 1.2° gap in `surface-card` between slices.
- Colours: people use `partner-1…6` in the fixed order (Aarav, Ishita, Kabir, Meera); categories use the brand ramp `chart-ink`, `lime`, `ink-secondary`, `ink-faint`, `line-strong`, so they never look like a partner.
- Hover a slice to show its exact amount in `cf-tip`.
