# Alert banner

Use an alert banner for a situation on the page that needs action (a settlement to record, books out of balance, a breached password): an icon disc, one bold line with the figure, one line of context, and the fixing action on the right.

- Classes: `cf-alert` plus `--graphite` (money owed between partners or sides: lime disc), `--warn` (out of balance, expiring), `--neg` (security, failures), `--info` (offline, notices), `--pos` (all clear). `cf-alert--slim` is the one-line version.
- Use `role="alert"` only for problems that appear while the person is on the page.
