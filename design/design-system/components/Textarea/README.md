# Textarea

Use a textarea for multi-line notes such as vault item notes, expense context and invite messages; show a character count once the person is near the limit.

- Class: `cf-textarea` (96 px minimum, resizes vertically). Same states as Text input: hover, focus, `disabled`, `aria-invalid`.
- Put the count in the label row (`cf-label-row` + `cf-help`) and the fix in `cf-errtext`.
