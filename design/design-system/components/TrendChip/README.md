# Trend chip

Use a trend chip to show change against the previous period next to a figure, with an arrow so the direction never relies on colour alone.

- Classes: `cf-trend--up` (positive soft), `cf-trend--down` (negative soft), `cf-trend--flat` (neutral: no change, or a rise in costs).
- Give it an `aria-label` that says the comparison ("Up 6% on September").
