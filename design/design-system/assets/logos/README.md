# Logos

- `coffer-lockup-on-light.svg` — Lime disc with a dark C, then the wordmark in ink `#1c1c1e`. Use it on `surface`, `surface-card` and `canvas` in the Light theme.
- `coffer-lockup-on-dark.svg` — The same lockup with the wordmark in white `#ffffff`. Use it on Dark-theme surfaces and on `graphite`.
- `coffer-wordmark-on-light.svg` — Wordmark alone, single ink `#1c1c1e`, for light grounds where the disc already appears nearby.
- `coffer-wordmark-on-dark.svg` — Wordmark alone, single ink `#ffffff`, for dark grounds.
- `coffer-monogram.svg` — Lime disc `#d6fe68` with the C in `#1c1c1e`. Works on light and dark grounds; use it in the nav rail and as the app icon.
- `favicon.svg` — The monogram for browser tabs (32px viewBox size).
- `favicon-32.png` — 32×32 PNG fallback of the favicon.
- `apple-touch-icon.png` — 180×180 square lime icon with the C, for home-screen shortcuts (the system rounds the corners).
